# Welcome to Open Heightz

Technology Belongs to Everyone.

Whether you are learning, teaching, building a business, or maintaining software, you can join in. **You do not need to be an expert.**

## Start here
1. Read the [project directory](OPEN_HEIGHTZ.md).
2. Choose one repository matching your interests.
3. Follow its README to try the project.
4. Report a clear bug, suggest an improvement, translate a guide, or help another learner.
5. Submit a pull request when ready, respecting project licences and accurate attribution.

## Community principles
Give credit. Keep documentation approachable. Do not share credentials or personal data. Disagree with ideas constructively. Ask before collecting user data. Mark experimental functionality honestly.
