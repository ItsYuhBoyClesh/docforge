# Open Heightz | Project directory

**Technology Belongs to Everyone.**  
**Founded by Clesh TN Maluleka** | [GitHub founder profile](https://github.com/ItsYuhBoyClesh)

Open Heightz is an emerging, community-oriented initiative developing free starter tools and learning resources. These projects are independently released under the MIT licence and welcome respectful contributions.

| Project | Purpose | How to use |
|---|---|---|
| [DevPath Open](https://github.com/ItsYuhBoyClesh/devpath-open) | Introductory programming lessons | Open `index.html` |
| [AccessCheck Lite](https://github.com/ItsYuhBoyClesh/accesscheck-lite) | Limited HTML accessibility checks | Open `index.html` |
| [DocForge](https://github.com/ItsYuhBoyClesh/docforge) | Python-generated project inventories | Run `python docforge.py --help` |
| [RepoGuardian](https://github.com/ItsYuhBoyClesh/repoguardian) | Limited repository secret/hygiene checks | Run `python repoguardian.py --help` |
| [OfflineFirst Kit](https://github.com/ItsYuhBoyClesh/offlinefirst-kit) | Offline-capable browser notes starter | Serve locally or on HTTPS |

## Our approach
Free to access; accessible by design; honest about limitations; contributor credit; practical learning; responsible security.

## Get involved
Choose a project, read its CONTRIBUTING.md and ROADMAP.md, test it, and open a focused issue or pull request. Beginners, educators, students, non-profits, small businesses and professional developers are welcome.

## Identity and rights
Open Heightz is a proposed initiative identity; no trademark registration or organizational incorporation is represented here. Founder recognition records the initiative's origin; it does not confer copyright over other people's contributions. See each repository's licence and credits.
